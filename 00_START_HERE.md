# Start Here

## Session instruction for AI

Copy this at the beginning of the session if useful:

> 这是一个严格限时的 software engineering coding interview。
>
> 请主要用中文和我讨论、分析和解释，以减少沟通成本。
>
> 所有代码、identifier、API name、file name、comment、docstring、test name、README、commit message 和 user-facing application text 都必须保持英文。
>
> 我会对最终技术决策负责。你可以帮助我做 analysis、scope calibration、implementation、debugging、testing、deployment planning 和 code review preparation。
>
> 当我要求你分析时，不要自动开始修改代码。
>
> 当你建议 architecture 或 implementation decision 时，请说明主要 trade-off。
>
> 优先目标：
> 1. correctness
> 2. end-to-end working prototype
> 3. deployability
> 4. explainability
> 5. testing
> 6. polish
>
> 不要为了显得复杂而 over-engineer。
> 如果某个 production concern 不值得在 3 小时 prototype 中实现，请明确告诉我，并把它留作 code review discussion。

## If Chinese input is unavailable

Use short English commands. Ask the AI to answer in Chinese:

> Please answer in Chinese. Keep all engineering artifacts in English.

Then use the micro-prompts in `09_ENGLISH_MICRO_PROMPTS.md`.
