# 14 没有中文输入法时：双语救命 Prompt

用途：

**看到中文说明 → 直接复制下面英文给 Claude。**
Claude 回复仍然可以要求中文。

最开始先发：

> 请用中文回答我，所有代码和工程产物保持英文。  
> Please answer me in Chinese. Keep all code and engineering artifacts in English.

---

## 一、选题和范围

### 比较候选题，不要开始写代码
中文意思：帮我比较这些题，先别写。

> Compare these prompts for a 3-hour build. Do not code yet.

### 根据我的背景选
中文意思：考虑我更熟 Python / FastAPI / backend。

> Which prompt best fits my background and gives me the highest chance of shipping a complete, deployable prototype in 3 hours?

### 把范围压到 3 小时
中文意思：不要给我做太大。

> Scope this strictly for a 3-hour interview.

### Senior Engineer 角度审查范围
中文意思：看看哪里太大、太小、太复杂。

> Review this scope as a senior engineer. What is too large, too small, or over-engineered?

### 砍功能
中文意思：直接告诉我什么不要做。

> Cut anything that is not necessary for a complete working prototype.

### 最小完整链路
中文意思：先告诉我最薄的端到端流程。

> What is the smallest meaningful end-to-end vertical slice?

---

## 二、开始实现

### 先计划，不要动代码
中文意思：先说你准备怎么做。

> Plan first. Do not edit any files yet.

### 告诉我会改什么
中文意思：列文件和原因。

> Tell me which files you plan to create or modify and why.

### 只做第一阶段
中文意思：别一次把整个项目都写完。

> Implement only the first stage. Do not expand the scope.

### 只做这个任务
中文意思：严格限制范围。

> Implement only this task. Do not touch unrelated code.

### 不要顺手重构
中文意思：别为了“更漂亮”乱改。

> Do not refactor unrelated code.

### 保持简单
中文意思：这是 3 小时 prototype。

> Keep this simple. This is a 3-hour prototype.

### 先做核心链路
中文意思：先让整个系统活起来。

> Prioritize the core end-to-end flow before adding optional features.

### 只实现一个 endpoint
中文意思：一次做一个接口。

> Implement only this endpoint and keep unrelated behavior unchanged.

### 先设计 API
中文意思：先定接口，不写代码。

> Design the minimal API first. Do not implement it yet.

### 先设计数据模型
中文意思：只保留 MVP 字段。

> Design the minimal data model for the MVP. Do not add unnecessary fields.

---

## 三、Review AI 生成的代码

### 检查是否过度设计
中文意思：AI 有没有写太多。

> Check whether this implementation is over-engineered for a 3-hour prototype.

### 检查我能不能解释
中文意思：太复杂就简化。

> Is there anything here that I may struggle to explain in a code review? Simplify if needed.

### Review diff
中文意思：像 senior engineer 看当前改动。

> Review the current git diff as a senior engineer.

### 分类问题
中文意思：现在修 / 有空修 / 只讨论。

> Separate issues into: fix now, fix if time remains, and discuss only in code review.

### 先解释代码
中文意思：我没懂，不准继续。

> Explain this code step by step before making any further changes.

---

## 四、Testing

### 告诉我最值得测什么
中文意思：不要追 coverage。

> What are the 5–8 highest-value tests for this project? Do not optimize for coverage percentage.

### 只测业务行为
中文意思：别测试框架。

> Focus on business behavior, not framework internals.

### 生成最小测试集
中文意思：pytest，少而值钱。

> Create a minimal, high-value pytest suite.

### 测 happy path
中文意思：补正常流程。

> Add one clear happy-path test.

### 测非法输入
中文意思：补 validation。

> Add a test for invalid input and verify the expected status code.

### 测 not found / conflict
中文意思：补关键错误情况。

> Add a test for the most important not-found or conflict case.

### 测试失败先判断谁错
中文意思：别直接改代码。

> Determine whether this failure is caused by the implementation, the test expectation, the fixture, or the environment. Do not edit yet.

### 跑全部测试
中文意思：最后整体跑一次。

> Run the full test suite and summarize any failures.

---

## 五、Debug

### Root cause first
中文意思：先找原因，别乱修。

> Root cause first. Do not edit yet.

### 给证据
中文意思：为什么你觉得是这个原因。

> What evidence supports that diagnosis?

### 最小验证
中文意思：先验证 hypothesis。

> What is the smallest experiment to verify this hypothesis?

### 最小修复
中文意思：别大改。

> Give me the smallest safe fix.

### 不要大重构
中文意思：不要为了一个 bug 改半个项目。

> Do not perform a large refactor to fix this bug.

### 一次一个 hypothesis
中文意思：不要同时改很多地方。

> Test one hypothesis at a time.

### 已经卡太久
中文意思：判断是不是该放弃。

> This bug has already taken too long. Should I keep fixing it, use a workaround, roll back, or cut scope?

### 看日志
中文意思：先从 error/log 入手。

> Check the logs first and identify the most likely failure point.

---

## 六、Deployment

### 现在该部署了吗
中文意思：判断是不是应该提前 deploy。

> Should I deploy now?

### 部署前 checklist
中文意思：别漏启动命令、端口、依赖这些。

> Give me the shortest deployment checklist for the current project.

### FastAPI 部署专项检查
中文意思：检查 uvicorn / app path / port 等。

> Check the FastAPI deployment setup: app import path, uvicorn command, host, port, dependencies, environment variables, and storage assumptions.

### 不要改业务逻辑
中文意思：这看起来是部署问题。

> This looks like a deployment problem. Do not change business logic yet.

### 根据日志诊断
中文意思：先看日志判断。

> Diagnose this deployment failure from the logs. Start with the most likely cause.

### 一次检查一个原因
中文意思：别乱改。

> Check one likely deployment cause at a time.

### 部署成功后的验证
中文意思：线上版本要再测。

> Deployment succeeded. Give me a short live verification checklist.

### 部署卡太久
中文意思：重新考虑时间。

> Deployment has already taken [X] minutes and I have [Y] minutes left. What is the smallest recovery path?

### 是否该停止折腾部署
中文意思：什么时候切 fallback。

> At what point should I stop debugging deployment and move to a fallback?

---

## 七、时间管理

### 剩 90 分钟
中文意思：重新排优先级。

> I have 90 minutes left. Re-prioritize based on the current project state.

### 剩 60 分钟
中文意思：砍 optional work。

> I have 60 minutes left. Cut optional work and prioritize deployment, correctness, tests, and cleanup.

### 剩 30 分钟
中文意思：禁止新功能。

> I have 30 minutes left. No new features.

### 剩 15 分钟
中文意思：停止开发，准备收尾。

> I have 15 minutes left. Stop development and prepare README, review notes, demo, and code review talking points.

### 我现在该做什么
中文意思：只要下一步。

> What is the single highest-value next step right now?

### 哪些该砍
中文意思：直接叫停低价值工作。

> What should I cut immediately?

### 是否正在做低价值工作
中文意思：帮我纠偏。

> Am I spending time on something low-value right now?

### 重新规划
中文意思：结合完成情况和 blocker 重排。

> Re-plan the remaining time based on what is done, what is missing, current blockers, and deployment status.

---

## 八、Final Check

### 禁止加功能
中文意思：冻结范围。

> Freeze the feature scope. Do not add anything optional.

### 最终 correctness review
中文意思：只找会让 demo 崩的问题。

> Find only critical correctness issues that could break the demo.

### 最终部署风险
中文意思：只找会让线上挂的问题。

> Find only deployment risks that could break the live demo.

### 清理
中文意思：只做低风险清理。

> Remove obvious debug code, dead code, and accidental complexity. Do not refactor broadly.

### README
中文意思：只写真实实现。

> Generate a concise README that accurately reflects only what is implemented.

### REVIEW_NOTES
中文意思：只记录 Tech Lead 值得问的东西。

> Update REVIEW_NOTES.md with only the decisions worth discussing with a Tech Lead.

---

## 九、Code Review 准备

### 60 秒开场
中文意思：自然介绍项目。

> Prepare a natural 60-second technical walkthrough of this project.

### 最重要的决定
中文意思：找 5–8 个值得讲的 decision。

> Identify the 5–8 most important engineering decisions I made.

### 替代方案和取舍
中文意思：为什么不选另一个方案。

> For each decision, give the alternative, trade-off, and production version.

### 找弱点
中文意思：预测 Tech Lead 会打哪里。

> Identify the 5 areas a Tech Lead is most likely to challenge.

### 100 倍流量
中文意思：系统先哪里坏。

> What would break first at 100x traffic?

### 并发
中文意思：当前设计有哪些 concurrency risk。

> What concurrency issues could exist in the current design?

### 幂等
中文意思：哪些操作应该 idempotent。

> Which operations should be idempotent, and are they currently idempotent?

### 安全
中文意思：prototype 缺哪些 security basics。

> What security basics are missing from this prototype?

### 可观测性
中文意思：生产环境怎么监控。

> What logs, metrics, and alerts would you add in production?

### 多一小时
> What would I do with one more hour?

### 多一天
> What would I do with one more day?

### Production
> What would change if this were going to production?

### AI 使用
中文意思：AI 帮了什么，我验证了什么。

> What did AI help with, what did I explicitly verify, and what AI output did I reject or change?

---

## 十、英文表达救急

### 把中文变成自然技术英语
中文意思：我知道要说什么，但英语组织慢。

> Rewrite the following idea as concise, natural technical English without changing the technical meaning:
> [PASTE]

### 不要写太复杂
中文意思：给我能说出口的句子。

> Use short, natural sentences. Avoid overly formal language.

### 给短答案
中文意思：面试时直接能说。

> Give me a 2–3 sentence answer I can say naturally in a technical interview.

---

## 十一、控制 Claude 输出

### 太长
> Your answer is too long. Give me the conclusion and next step only.

### 只要 5 个 bullet
> Limit the answer to 5 bullets.

### 不重复背景
> Do not repeat context I already gave you.

### 只告诉我下一步
> Tell me only the next action, why it matters, and the success criterion.

# 最常用的 15 句

1. `Plan first. Do not edit yet.`  
   先计划，不要动代码。

2. `Implement only this step.`  
   只做这一步。

3. `Do not expand the scope.`  
   不要扩范围。

4. `Keep it simple.`  
   保持简单。

5. `Review the current diff.`  
   检查当前改动。

6. `Root cause first.`  
   先找根因。

7. `Smallest safe fix only.`  
   只做最小安全修复。

8. `Run the tests.`  
   跑测试。

9. `Should I deploy now?`  
   我现在该部署了吗？

10. `Diagnose from the logs first.`  
    先根据日志诊断。

11. `I have 60 minutes left. Re-prioritize.`  
    我还剩 60 分钟，重新排优先级。

12. `What should I cut?`  
    什么该砍？

13. `No new features.`  
    不加新功能。

14. `What will a Tech Lead challenge?`  
    技术负责人最可能问什么？

15. `Prepare my code-review talking points.`  
    帮我准备 code review 要点。
