# 99 现场一页速查

## 前 15 分钟
- 看完所有题
- AI 比较题目
- 我做最终选择
- 定 scope
- 定 architecture
- 定 180min plan

## 第一目标
**尽快 working vertical slice**

## 第二目标
**尽早 deploy**

## 永远不要
- over-engineer
- 无限加 feature
- 盲信 AI
- 为一个 bug 卡太久
- 最后 10 分钟第一次 deploy
- 写自己解释不了的代码

## 关键 Prompt
- 先分析，不要改代码
- 如果你是 senior engineer，你会怎么定义 3h scope？
- 这个方案哪里 over-engineered？
- 我还剩 X 分钟，重新 prioritize
- Root cause first. Do not edit yet.
- Review current diff
- What will a Tech Lead challenge?
- What should I discuss instead of implementing?

## 最后 45 分钟
- freeze features
- tests
- deployment verify
- README
- REVIEW_NOTES
- code review prep

## Code Review 必讲
- what I built
- why this architecture
- why this stack
- what I intentionally left out
- biggest trade-offs
- tests
- deployment
- limitations
- production changes
- AI: what I used / verified / rejected

## 一句话心态
**Ship a coherent system I understand completely.**
