# 10 最后 45 分钟冻结与检查

## Freeze Rule

进入最后 30–45 分钟后：

**不要新增 optional feature。**

只有以下情况允许继续实现：
- 题目明确 must-have 缺失
- critical correctness bug
- deployment blocker

- [ ] Validation works

- [ ] No obvious crash path

### Tests

- [ ] Critical failure（如相关）

### Deployment
- [ ] Live service reachable

- [ ] Logs clean enough

### Code
- [ ] Remove debug junk

- [ ] Names clear
- [ ] No dead code

- [ ] I understand every important file

### Documentation
- [ ] README

### Review prep
